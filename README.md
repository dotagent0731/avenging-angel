# 复仇天使

## 项目介绍

复仇天使希望为个人 AI Agent 提供一份脱敏的社交风险参考资料。用户可以整理自己在真实生活中遇到的令人不适或造成伤害的互动，将其中可观察的行为特征、互动模式、标注可信度的评价和必要的脱敏背景归纳到 `data/` 中。

个人 Agent 可以阅读这些资料，在日常社交中帮助用户留意欺骗、胁迫、操控、反复侵犯边界等行为信号，提醒用户核实情况、保护隐私和维护自身边界，为社交建立一道风险提醒“防火墙”。本项目目前处于初始化阶段，以下内容说明预期用途和贡献规则。

## 数据与隐私规则

**上传前须逐条删除或模糊化个人身份信息，确保每条信息本身不足以识别具体个人。**

- 可记录概括后的行为特征、标注可信度的评价，以及必要的脱敏背景。
- 禁止包含姓名、网名、账号、联系方式、住址、具体工作单位等身份线索，以及人脸、声纹、原始聊天记录或截图。
- 仅替换姓名不等于完成逐条脱敏。时间、地点、职业、关系和事件细节分别检查；单条仍过于具体的信息须删除或进一步概括。本项目不分析多条身份信息在段落之间、路径与正文之间或整份记录中的组合识别风险。逐条脱敏不保证绝对匿名。
- 不将性别、种族、国籍、宗教、年龄、健康状况等人口或健康特征作为判断风险的依据。

## 使用边界

个人经历带有主观性，也受具体情境影响。允许保留个人感受、人格评价和行为评价，但每条评价必须标注可信度；可信度统一使用下文的“主观判断、孤立证据、弱证据、强证据”四档。记录仍须区分可观察的行为与评价、推测；不能把评价或分类名称当作已经证实的事实。令人不适的经历不能证明对方有罪，这些资料也不能用于预测某个具体的人一定会伤害用户。

Agent 应将资料用于提示需要核实的行为风险，不得用于识别或追踪具体个人、建立人员黑名单、歧视，或自动作出影响他人就业、住房、信贷等权益的重大决定。

## 目录结构

```text
复仇天使/
├── data/
├── skill/
├── tool/
└── README.md
```

- `data/`：数据目录。
- `skill/`：存储帮助用户通过 Agent 上传脱敏数据的技能，上传内容须遵守上述数据与隐私规则。
- `tool/`：工具目录。

## 数据组织约定

上传后的资料按每个匿名人物归入一个目录，外层依次按国籍和地区组织：`data/<国籍>/<地区>/<匿名人物 ID>/`。人物目录只用于归纳脱敏经历，不用于确认现实身份、跨来源追踪或建立人员名单。以下是文档约定，尚未实现自动上传、分类或校验功能。

- 匿名人物 ID 使用与现实身份无关联的随机标识，不得使用姓名、账号、联系方式、这些信息的编码或哈希，也不得保存身份对照表。
- 国籍不得根据姓名、外貌、语言等线索推断。地区只保留必要的粗粒度范围，不记录详细地址、具体单位或活动地点。
- 国籍或地区不明确时使用 `unknown`；不宜披露或该条信息本身过于具体时使用 `withheld`。路径中的每条身份信息与正文中的信息分别脱敏，不进行组合识别风险分析。
- 国籍和地区仅用于资料分类，不得用于风险评分、判断个人是否有害，或对任何群体作出概括。

### 多语言人物描述

当前文档约定支持中文和英文，人物目录中分别使用 `zh-CN.md` 和 `en.md`。每份人物描述均包含简介，并在简介后增加一级标题 `# 记录`；英文对应为 `# Records`。不良记录直接写在各语言的人物 Markdown 文件中，不存储在子目录或单独的记录文件中。更新资料时，中英文的简介、记录分类、内容及证据等级应保持一致。

“记录”下使用二级标题 `## <确凿程度>-<严重程度>` 分组，例如 `## 孤立证据-不礼貌行为`。同一分类下的多条记录使用三级标题分别命名，内容及证据说明写在相应条目下；英文使用含义对应的标题。允许先创建分类标题并标注“预留，暂无记录”，后续再补充内容；预留标题不表示已有相关事件。

其他补充资源仍可使用子目录，其名称和层级可以自由制定，但须在简介中声明相对路径、用途和内容范围。不再为不良记录保留子目录声明、目录索引或空目录占位文件。任何位置中的身份信息均须逐条脱敏。

后续 Agent 应先阅读对应语言的简介，再按需阅读同一文档“记录”下的相关分类和条目；补充资源按简介中的声明检索。不得仅凭国籍、地区或匿名人物 ID 判断风险。

以下仅为结构占位示例，不代表真实人物或现有数据：

```text
data/
└── <国籍或 unknown/withheld>/
    └── <粗粒度地区或 unknown/withheld>/
        └── <无身份关联的随机 ID>/
            ├── zh-CN.md
            └── en.md
```

每份语言文档可采用以下最小提纲；英文版本使用对应的英文标题和说明：

```markdown
# 匿名人物描述

## 简介

概括可观察的行为模式、必要的脱敏背景、资料适用范围及不确定性。

# 记录

## 孤立证据-不礼貌行为

预留，暂无记录。

## 主观判断-不道德行为

预留，暂无记录。

## 主观判断-恶劣行为

预留，暂无记录。
```

既无记录也无预留分类标题时，在“记录”下注明“暂无记录”。新增、调整或删除分类与条目时同步更新两种语言。已有记录子目录须将正文、分类、证据等级及证据说明迁入文档中的对应分类；确认内容完整迁移后移除原记录文件与空目录。

### 不良记录分类

每个人物都可以提交不良记录。每条记录分别标注严重程度与确凿程度，两者独立选择，四档与四档自由组合，共 16 种分类。分级针对具体记录，不是对整个人物的风险评分。

严重程度约定如下：

| 严重程度 | 内容范围 |
| --- | --- |
| 不礼貌行为 | 礼节、沟通或尊重方面的不当行为。 |
| 不道德行为 | 涉及诚信、责任或道德规范的问题。 |
| 恶劣行为 | 造成明显伤害、反复侵犯边界、胁迫或严重操控等行为。 |
| 违法犯罪行为 | 记录者认为可能涉及违法或犯罪的行为；分类本身不构成违法认定或定罪。 |

确凿程度同时用于标注评价的可信度：

| 确凿程度／评价可信度 | 依据范围 |
| --- | --- |
| 主观判断 | 基于个人感受、印象或推测，不需要提供任何证据。 |
| 孤立证据 | 证据可提供，也可不提供；单纯的上传者证词也属于一种孤立证据，不要求附加材料或交叉验证。 |
| 弱证据 | 必须提供证据，但不要求这些证据来自有公信力的来源；证据链尚不足以将完整记录确定为严格事实。 |
| 强证据 | 必须提供证据，且至少一条来自有公信力的来源；还必须能依据证据链将记录确定为严格事实。 |

“有公信力的来源”须能够核验来源主体、材料出处及其可靠性。强证据记录应说明至少一条符合该条件的证据，以及各项证据如何共同支持记录的具体事实；仅引用一个有公信力的来源，不代表证据链已经完整，也不能把仍需猜测的结论认定为严格事实。这里的强证据是项目内部分类，不等于法律上的定案标准。

证据可以采用脱敏后的材料摘要、必要引用或不含身份线索的出处说明。证据要求不豁免逐条脱敏规则，也不允许上传原图、原始聊天记录或截图。

不得根据严重程度自动提高确凿程度，也不得仅按材料数量决定证据强弱。评价示例：“人物 A 掌控欲较强（可信度：主观判断）”。同一记录含多条评价时，分别标注；记录的确凿程度不自动适用于其中的每条评价。

不良记录分类以人物文档中的二级标题 `<确凿程度>-<严重程度>` 表示，挂在一级标题“记录”下；分类标题与条目中的两项分类须一致。下表各单元格是可用的分类标题，16 种组合均可使用：

| 严重程度＼确凿程度 | 主观判断 | 孤立证据 | 弱证据 | 强证据 |
| --- | --- | --- | --- | --- |
| 不礼貌行为 | `主观判断-不礼貌行为` | `孤立证据-不礼貌行为` | `弱证据-不礼貌行为` | `强证据-不礼貌行为` |
| 不道德行为 | `主观判断-不道德行为` | `孤立证据-不道德行为` | `弱证据-不道德行为` | `强证据-不道德行为` |
| 恶劣行为 | `主观判断-恶劣行为` | `孤立证据-恶劣行为` | `弱证据-恶劣行为` | `强证据-恶劣行为` |
| 违法犯罪行为 | `主观判断-违法犯罪行为` | `孤立证据-违法犯罪行为` | `弱证据-违法犯罪行为` | `强证据-违法犯罪行为` |

分类章节可先写成：

```markdown
# 记录

## 孤立证据-不礼貌行为

预留，暂无记录。
```

其他分类按同样方式增加二级标题。后续有内容时在对应分类下填写条目，并移除该分类的“预留，暂无记录”标记。仅预留需要使用的分类，也可以预留全部 16 种组合，无需创建目录、单独的记录文件或占位事件。

每条记录正文至少包含标题、严重程度、确凿程度及内容，中英文副本须保持含义和等级一致。证据部分按等级要求填写：主观判断不需要证据，可省略整个证据部分；孤立证据可提供材料，也可仅写上传者证词，不强制单独填写证据部分；弱证据与强证据必须填写证据，强证据还须说明公信力来源与事实证据链。以下为包含证据部分的模板：

```markdown
# 记录

## <确凿程度>-<严重程度>

### <记录标题>

- 严重程度：<四档之一>
- 确凿程度：<四档之一>

#### 内容

填写脱敏后的行为描述或评价；每条评价标注“可信度：<四档之一>”。

#### 证据与局限

按所选等级概括支持判断的材料，以及尚不明确的部分。强证据须列明至少一条有公信力的来源，并解释证据链如何确定该记录为严格事实。不附原始截图、身份线索或其他未经脱敏的原始内容。
```

## 技能清单与使用

- [敏感信息过滤](skill/sensitive-information-filter/SKILL.md)：在上传前处理中文、英文或混合描述，逐条删除或泛化人物标识、地名、组织名及其他身份线索，不进行组合识别风险分析。允许保留标注可信度的评价，核对不良记录的严重程度、确凿程度及相应证据要求，并保留必要的行为含义和不确定性。对违法犯罪、涉黄等表述去除露骨细节和定罪式标签，但不掩盖胁迫、威胁或未成年人安全风险。

让 Agent 读取该技能并处理已授权的文本，先返回脱敏草稿及 `pass`、`needs_review` 或 `reject` 状态。用户预览后，后续保存或上传仍须获得相应授权；该技能不自动保存或上传，不保证绝对匿名。当前交付为技能说明与[行为验收案例](skill/sensitive-information-filter/references/test-cases.md)，不是已实现的自动上传或过滤程序，也不包含图像信息提取。
