# 复仇天使

## 项目介绍

复仇天使希望为个人 AI Agent 提供一份脱敏的社交风险参考资料。用户可以整理自己在真实生活中遇到的令人不适或造成伤害的互动，将其中可观察的行为特征、互动模式和必要的脱敏背景归纳到 `data/` 中。

个人 Agent 可以阅读这些资料，在日常社交中帮助用户留意欺骗、胁迫、操控、反复侵犯边界等行为信号，提醒用户核实情况、保护隐私和维护自身边界，为社交建立一道风险提醒“防火墙”。本项目目前处于初始化阶段，以下内容说明预期用途和贡献规则。

## 数据与隐私规则

**绝对不允许上传真实个人信息，或任何能够直接、间接识别具体个人的信息。**

- 仅记录概括后的行为特征，以及理解该行为所必需的脱敏背景。
- 禁止包含姓名、网名、账号、联系方式、住址、具体工作单位等身份线索，以及人脸、声纹、原始聊天记录或截图。
- 仅替换姓名不等于完成脱敏。时间、地点、职业、关系和事件细节的组合也可能暴露身份；能够重新识别个人的信息必须删除或进一步概括。
- 不将性别、种族、国籍、宗教、年龄、健康状况等人口或健康特征作为判断风险的依据。

## 使用边界

个人经历带有主观性，也受具体情境影响。记录应区分可观察的行为、个人感受与推测，并保留必要的不确定性。令人不适的经历不能证明对方有罪，这些资料也不能用于预测某个具体的人一定会伤害用户。

Agent 应将资料用于提示需要核实的行为风险，不得用于识别或追踪具体个人、建立人员黑名单、歧视，或自动作出影响他人就业、住房、信贷等权益的重大决定。

## 目录结构

```text
复仇天使/
├── data/
├── skill/
├── tool/
└── README.md
```

- `data/`：数据目录。
- `skill/`：存储帮助用户通过 Agent 上传脱敏数据的技能，上传内容须遵守上述数据与隐私规则。
- `tool/`：工具目录。

## 数据组织约定

上传后的资料按每个匿名人物归入一个目录，外层依次按国籍和地区组织：`data/<国籍>/<地区>/<匿名人物 ID>/`。人物目录只用于归纳脱敏经历，不用于确认现实身份、跨来源追踪或建立人员名单。以下是文档约定，尚未实现自动上传、分类或校验功能。

- 匿名人物 ID 使用与现实身份无关联的随机标识，不得使用姓名、账号、联系方式、这些信息的编码或哈希，也不得保存身份对照表。
- 国籍不得根据姓名、外貌、语言等线索推断。地区只保留必要的粗粒度范围，不记录详细地址、具体单位或活动地点。
- 国籍或地区不明确时使用 `unknown`；不宜披露或组合后可能暴露身份时使用 `withheld`。即使单项看似匿名，也必须检查整条路径与正文组合后的重新识别风险。
- 国籍和地区仅用于资料分类，不得用于风险评分、判断个人是否有害，或对任何群体作出概括。

### 多语言人物描述

当前文档约定支持中文和英文，人物目录中分别使用 `zh-CN.md` 和 `en.md`。每份人物描述均包含简介，以及各子目录的内容说明和索引。更新资料时，中英文的简介、子目录清单和说明应保持一致。

子目录的名称、层级和内容可以自由制定，没有固定分类要求；但所有实际存在的子目录都必须在简介中声明相对路径、用途和内容范围。自由组织不豁免数据与隐私规则，任何层级都不得存储可识别个人的信息。

后续 Agent 应先阅读对应语言的简介，根据其中的概括和子目录声明判断资料是否与当前问题相关，再按需进入相关子目录；不得仅凭国籍、地区或匿名人物 ID 判断风险。

以下仅为结构占位示例，不代表真实人物或现有数据：

```text
data/
└── <国籍或 unknown/withheld>/
    └── <粗粒度地区或 unknown/withheld>/
        └── <无身份关联的随机 ID>/
            ├── zh-CN.md
            ├── en.md
            ├── <自定义子目录 A>/
            └── <自定义子目录 B>/
```

每份语言文档可采用以下最小提纲；英文版本使用对应的英文标题和说明：

```markdown
# 匿名人物描述

## 简介

概括可观察的行为模式、必要的脱敏背景、资料适用范围及不确定性。

### 子目录声明

- `<相对路径 A>/`：用途、内容范围，以及何时值得进一步检索。
- `<相对路径 B>/`：用途、内容范围，以及何时值得进一步检索。

## 子目录内容与索引

- [自定义子目录 A](<相对路径 A>/)：该目录内容的简要说明。
- [自定义子目录 B](<相对路径 B>/)：该目录内容的简要说明。
```

没有子目录时，在简介中注明“暂无子目录”；新增、重命名或删除子目录时，同步更新各语言文档的简介声明和索引。

## 技能清单与使用

- [敏感信息过滤](skill/sensitive-information-filter/SKILL.md)：在上传前处理中文、英文或混合描述，删除人物标识，按依据泛化地名、组织名及其他身份线索，并保留必要的行为含义和不确定性。对违法犯罪、涉黄等表述去除露骨细节和定罪式标签，但不掩盖胁迫、威胁或未成年人安全风险。

让 Agent 读取该技能并处理已授权的文本，先返回脱敏草稿及 `pass`、`needs_review` 或 `reject` 状态。用户预览后，后续保存或上传仍须获得相应授权；该技能不自动保存或上传，不保证绝对匿名。当前交付为技能说明与[行为验收案例](skill/sensitive-information-filter/references/test-cases.md)，不是已实现的自动上传或过滤程序，也不包含图像信息提取。
